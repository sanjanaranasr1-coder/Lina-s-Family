Pedagogical Guide (NCERT Class 1)

🎯 Chapter Learning Objectives:

  • Understand spatial vocabulary: nearest, farthest, top, bottom.
  • Compare physical attributes: tallest/shortest, longest/shortest, thickest/thinnest.
  • Measure lengths using non-standard units (handspan, fingers, footspan).
  • Understand relative weight (heavy vs light) using balance scales.
  • Develop capacity concepts (holding more vs holding less) and water conservation awareness.

💡 Home / Classroom Activity Tips:

Ask the child to measure their study table or bed using their own handspan and compare it with an adult's handspan. Explain why adults need fewer handspans (because adult hands are larger!).
